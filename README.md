# 🩺 진료실 도우미

병원에 가면 "무슨 약 드세요?", "언제부터 아프셨어요?", "수술하신 적 있으세요?"에 답하기 어렵고, 물어보려던 것도 잊기 쉽습니다. 진료실 도우미는 **폰 화면 한 장**으로 이걸 해결합니다.

- **무료**, 가입 없음, 광고 없음
- 서버가 없고 **모든 기록은 그 폰에만** 저장됩니다
- 홈 화면에 설치하면 앱처럼 열리고 **인터넷 없이도** 동작합니다

주소: https://kimda-woon.github.io/easy-helper/

## 기능 (1단계)

| 버튼 | 하는 일 |
|---|---|
| 🩺 의사 선생님께 보여 주기 | 이름·나이·혈액형, ⚠️알레르기, 지병, 먹는 약 표, 오늘 여쭤볼 것(답 들으면 ✓), 수술 이력, 최근 진료를 한 화면에. 약 봉투 사진을 크게 보기, 종이로 뽑기 |
| 💊 내 약 | **📷 약 봉투 찍어서 넣기**: 폰 안에서 글자를 읽어 약 이름·병원·날짜·하루 몇 번·며칠 치를 채우고, 확인 화면에서 "맞아요" 한 번으로 저장. 옆으로 누운 사진도 방향을 찾아 읽음. 같은 약을 다시 받아 오면 새로 만들지 않고 날짜만 갱신. 직접 적어 넣기도 가능. 약이 5일 안에 떨어지면 첫 화면에 알림 |
| ❓ 물어볼 것 | 약·몸 상태·검사·서류 질문을 **눌러서 고르기**. 직접 적기도 가능 |
| 📋 병원 다녀왔어요 | **버튼 3번**: 어느 병원·언제 → 의사 말씀(괜찮대요/약이 바뀌었어요…) → 다음 진료(1주/2주/한 달/3달/큰 달력으로 날짜 고르기). 다음 예약이 첫 화면에 뜨고, 예약일이 지나면 "다녀오셨어요?"를 물어봄 |
| 🗓️ 진료 기록 | 지난 진료와 예약 목록, 예약 직접 넣기 |
| 🗂️ 내 병력 | 기본 정보, 알레르기, 지병, 수술·시술(기억나지 않을 때 찾는 곳 안내), 자주 가는 병원, 검사 결과지 사진(지우기 가능) |
| ⚙️ 설정 | 앱 설치, 글자 크기, 백업(사진 포함)·가져오기, 모두 지우기 |

예전 "든든 도우미"를 쓰던 폰이면 응급 정보(이름, 혈액형, 지병, 알레르기, 약, 병원)를 처음 한 번 자동으로 옮겨 옵니다.

## 알아둘 점

- 기록을 보여 주는 도구이며 진단이나 처방을 대신하지 않습니다.
- **아이폰은 꼭 홈 화면에 설치**하세요. 설치하지 않은 웹사이트의 기록은 한동안 안 쓰면 지워질 수 있습니다. 가끔 **백업**을 내보내 가족 폰에 보관하세요.
- 약 목록을 처음 만들 때는 건강보험심사평가원 "내가 먹는 약! 한눈에"에서 최근 처방 약을 확인하면 빠뜨리지 않습니다.

## 함께 먹을 때 주의 (참고용)

- 자주 먹는 약 약 80개 성분과 상품명(복합제 포함)을 앱 안 사전(`drugs.js`)으로 가지고 있어, 약 이름에서 성분을 찾습니다.
- 널리 알려진 위험 조합(예: 항응고제+소염진통제, 질산염+발기부전약, 마약성 진통제+수면·안정제, 심바스타틴+클래리스로마이신)과 같은 성분·같은 종류 중복(예: 타이레놀+울트라셋)을 찾아 **위험 / 확인 필요**로 표시합니다.
- 내 약 목록 위, 진료실 화면, (위험 조합이면) 첫 화면에 나오고, "물어볼 것에 넣기"로 진료 때 바로 물어볼 수 있습니다.
- **공식 병용금기 목록 전체가 아니며, 경고가 없다고 안전하다는 뜻이 아닙니다.** 사전에 없는 약은 "성분 확인 안 됨"으로 표시하고 검사에서 빠집니다. 약사·의사의 검토를 받아 규칙을 보완하는 것을 권합니다.

## 약 봉투 읽기에 대해

- 글자 읽기는 [Tesseract.js](https://github.com/naptha/tesseract.js)로 **폰 안에서** 합니다. 사진은 밖으로 나가지 않습니다. 처음 한 번만 글자 읽기 도구(약 5MB)를 인터넷에서 받고, 그 뒤로는 저장해 두고 씁니다.
- 약 이름이 틀리게 읽힐 수 있어서 **항상 확인 화면을 거칩니다.** 용량이 확실하지 않으면 비워 둡니다(틀린 용량보다 안전).
- 인쇄된 글씨는 잘 읽고, 흐리거나 구겨진 종이, 손글씨는 잘 못 읽습니다.
