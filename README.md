# 🩺 진료실 도우미

병원에 가면 "무슨 약 드세요?", "언제부터 아프셨어요?", "수술하신 적 있으세요?"에 답하기 어렵고, 물어보려던 것도 잊기 쉽습니다. 진료실 도우미는 **폰 화면 한 장**으로 이걸 해결합니다.

- **무료**, 가입 없음, 광고 없음
- 서버가 없고 **모든 기록은 그 폰에만** 저장됩니다
- 홈 화면에 설치하면 앱처럼 열리고 **인터넷 없이도** 동작합니다

주소: https://kimda-woon.github.io/easy-helper/

## 기능 (1단계)

| 버튼 | 하는 일 |
|---|---|
| 🩺 의사 선생님께 보여 주기 | 이름·나이·혈액형, ⚠️알레르기, 지병, 먹는 약 표, 오늘 여쭤볼 것(답 들으면 ✓), 수술 이력, 최근 진료를 한 화면에. 약 봉투 사진을 크게 보기, 종이로 뽑기 |
| 💊 내 약 | 약 이름·용량·먹는 때(버튼)·밥이랑·처방 병원·처방일·며칠 치, 약 봉투 사진. 약이 5일 안에 떨어지면 첫 화면에 알림. 그만 먹는 약 보관 |
| ❓ 물어볼 것 | 약·몸 상태·검사·서류 질문을 **눌러서 고르기**. 직접 적기도 가능 |
| 📋 병원 다녀왔어요 | **버튼 4번**: 어느 병원 → 의사 말씀(괜찮대요/약이 바뀌었어요…) → 다음 진료(1주/2주/한 달/3달) → 받아 온 종이 사진. 다음 예약이 첫 화면에 뜨고, 예약일이 지나면 "다녀오셨어요?"를 물어봄 |
| 🗓️ 진료 기록 | 지난 진료와 예약 목록, 예약 직접 넣기 |
| 🗂️ 내 병력 | 기본 정보, 알레르기, 지병, 수술·시술, 자주 가는 병원, 검사 결과지 사진 |
| ⚙️ 설정 | 앱 설치, 글자 크기, 백업(사진 포함)·가져오기, 모두 지우기 |

예전 "든든 도우미"를 쓰던 폰이면 응급 정보(이름, 혈액형, 지병, 알레르기, 약, 병원)를 처음 한 번 자동으로 옮겨 옵니다.

## 알아둘 점

- 기록을 보여 주는 도구이며 진단이나 처방을 대신하지 않습니다.
- **아이폰은 꼭 홈 화면에 설치**하세요. 설치하지 않은 웹사이트의 기록은 한동안 안 쓰면 지워질 수 있습니다. 가끔 **백업**을 내보내 가족 폰에 보관하세요.
- 약 목록을 처음 만들 때는 건강보험심사평가원 "내가 먹는 약! 한눈에"에서 최근 처방 약을 확인하면 빠뜨리지 않습니다.
