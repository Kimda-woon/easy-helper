# 💚 든든 도우미

어르신 폰에 깔아 두고 바로 쓰는 도구 모음입니다. 서버 없이 폰 브라우저에서 돌아가고, 모든 내용은 그 폰에만 저장됩니다.

## 기능

| 버튼 | 하는 일 |
|---|---|
| 🔍 크게 보기 | 카메라 돋보기. 확대, 멈춰서 보기, 손가락으로 밀기, 또렷하게/검은 바탕 보기, 플래시(지원하는 폰) |
| 📄 쉬운 말로 풀기 | 글자로 넣으면 어려운 낱말을 쉬운 말로 바꾸고, 날짜·금액·사기 의심 신호를 짚어 줌. AI 키를 넣으면 사진 속 글도 읽고 "무슨 내용 / 하실 일 / 날짜·금액 / 조심할 점"으로 풀어 줌. 🔊 읽어 주기 |
| 📍 가족에게 연락 | 버튼 하나로 내 위치(카카오맵 링크)를 담은 문자 앱을 열고, 바로 전화 걸기 |
| 🚑 응급 정보 | 지병·약·알레르기·보호자 연락처를 구급대원에게 보여 줄 화면, 119 버튼, 지갑 카드 인쇄 |
| 💚 안부 보내기 | 오늘 기분(좋아요/그저 그래요/좀 아파요)을 골라 가족에게 안부 문자 |
| ⚙️ 설정 | 문자에 쓸 이름, 글자 크기, 가족 연락처, 응급 정보, AI 키, 백업 |

## 알아둘 점

- 웹사이트는 문자를 **대신 보낼 수 없어서**, 내용을 채운 문자 앱을 열어 줍니다. 어르신은 **보내기**만 누르면 됩니다.
- 안부를 "안 보냈을 때" 가족에게 자동으로 알리는 기능은 서버가 필요해서 아직 없습니다.
- 사진 풀이는 [Anthropic API](https://console.anthropic.com) 키가 필요하고, 쓸 때마다 요금이 나옵니다. 키는 그 폰의 브라우저에만 저장됩니다. 사용 한도를 정해 둔 키를 쓰세요.
- 카메라와 위치는 `https://` 주소에서만 동작합니다. GitHub Pages로 배포하면 됩니다.

## 배포

저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save. 폰에서 주소를 열고 "홈 화면에 추가"를 해 두세요.
