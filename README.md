# 💚 든든 도우미

어르신 폰에 깔아 두고 바로 쓰는 도구 모음입니다. **돈이 들지 않고**, 서버 없이 폰 브라우저에서 돌아가며, 내용은 그 폰에만 저장됩니다.

## 기능

| 버튼 | 하는 일 |
|---|---|
| 📖 글씨 읽어 주기 | 카메라에 비추면 크게 보여 주고(＋/－, 손가락으로 밀기, 플래시), **읽어 주세요**를 누르면 폰 안에서 글자를 인식해 어려운 말을 쉬운 말로 풀고 날짜·금액·사기 신호를 짚은 뒤 소리 내어 읽어 줌. 받은 문자는 붙여 넣어서 풀 수도 있음 |
| 📍 가족에게 연락 | 누르면 3초 뒤(취소 가능) 내 위치를 **가족 폰에 푸시 알림으로 자동 전송**. 알림을 누르면 카카오맵이 열림. 이어서 전화 버튼 |
| 🚑 응급 정보 | 지병·약·알레르기·보호자를 구급대원에게 보여 줄 화면, 119 버튼, 지갑 카드 인쇄 |
| 💚 안부 보내기 | 😊 잘 있어요 / 😐 그저 그래요 / 😣 좀 아파요 중 하나를 누르면 가족에게 바로 알림 |
| ⚙️ 설정 (가족용) | 이름, 가족 연락처, 알림 연결, 글자 크기, 응급 정보, 백업 |

## 누구나 무료로 쓰기

주소 하나(`https://kimda-woon.github.io/easy-helper/`)를 나눠 주면 됩니다. 설정은 폰마다 따로 저장되고, 알림 연결 코드도 집집마다 무작위로 따로 만들어집니다. 서버가 없어서 운영 비용도 없습니다.

## 앱처럼 설치 (홈 화면 아이콘)

설정 → **📲 앱처럼 설치하기**. 안드로이드 크롬은 버튼 한 번, 아이폰 사파리는 공유 → 홈 화면에 추가. 설치하면 인터넷이 약해도 첫 화면과 응급 정보가 열리고, 글자 인식 도구도 한 번 받은 뒤로는 저장해 두고 씁니다.

## 가족 알림 연결 (무료, 한 번만)

알림은 무료 오픈소스 푸시 서비스 [ntfy](https://ntfy.sh)를 씁니다. 가입이 필요 없습니다.

1. 어르신 폰: 설정 → **🔗 알림 연결 만들기** → QR코드가 나옴
2. 가족 폰: 카메라로 QR을 찍으면 안내 페이지(`connect.html`)가 열림 → ntfy 앱 설치 → **앱에 바로 추가하기** (안 되면 코드 입력)
   - 멀리 사는 가족에게는 **📤 링크 보내기**로 같은 안내 페이지를 카톡으로 보냄
3. 어르신 폰: **🔔 시험 알림 보내기**로 확인, **📍 위치 사용 미리 허락하기**

알림을 못 보내면(인터넷 끊김, 연결 전) 자동으로 문자 앱을 열어 기본 연락처에게 보낼 준비를 합니다.

## 알아둘 점

- 코드를 아는 사람은 누구나 알림을 볼 수 있으니 가족끼리만 공유하세요. 알림은 ntfy 서버에 최대 12시간 보관됩니다.
- 글자 인식은 [Tesseract.js](https://github.com/naptha/tesseract.js)로 폰 안에서 처리합니다. 처음 한 번은 인식 도구(약 5MB)를 내려받느라 인터넷이 필요하고 30초쯤 걸립니다. 인쇄된 글씨는 잘 읽고, 손글씨나 흐린 사진은 잘 못 읽습니다.
- 안부를 "안 보냈을 때" 자동으로 알리는 기능은 없습니다.
- 카메라와 위치는 `https://` 주소에서만 동작합니다. GitHub Pages로 배포하면 됩니다.

## 배포

저장소 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save. 폰에서 주소를 열고 "홈 화면에 추가"를 해 두세요.
